# Japan Travel Buddy Development Rules

## Project
Japan Travel Buddy

## Goal
Build an AI travel planner for visitors to Japan.

## Tech Stack
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Firebase
- Firestore
- OpenAI Responses API
- Google Maps API

## Development Rules

- Modify only one file at a time.
- Do not change component responsibilities.
- Preserve the existing architecture unless explicitly requested.
- Return complete copy-paste-ready code.
- Explain what file is being modified before generating code.
- Keep TypeScript type safety.
- Keep the project buildable after every change.

## UI Rules

- Mobile First
- Clean and modern UI
- Japanese language UI unless otherwise specified

## Data Rules

- Spot Database is the single source of truth.
- Do not create fake tourist spots.
- Prefer reusable components.

## Current Phase

Version 1.1
Focus:
- Dashboard improvements
- Mobile UI improvements
- Google Maps improvements
- PDF improvements
- AI travel quality improvements

Always prioritize code quality over adding new features.
